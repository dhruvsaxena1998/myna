# 14: Release and auto-update

**Status:** draft
**Spec stories:** 4
**Depends on:** 01

A signed, notarized DMG a teammate can install, and auto-update from GitHub Releases.

## Stories
- As a user, I want to install from a DMG without Gatekeeper warnings.
- As a user, I want the app to update itself.

## Done when
- [ ] Release workflow on tag push only
- [ ] About shows version and update status
- [ ] A teammate installs on a clean Mac

Menu bar: bolder glyph, and a better recording state

Real size: a 24 pt menu bar with 13 pt text, light and dark wallpaper. The orange capsule is macOS’s own microphone indicator, which shows whenever Myna records, so the options are judged next to it.

1 · The glyph, bolder

Same drawing as today; only the stroke weight changes. macOS’s own menu bar symbols sit around the 1.8–2.0 mark at this size.

2 · While recording

All use the 1.9 glyph. The timer ticks so you can judge jitter; digits are tabular so it never shifts the icons beside it.

  • Today: the tray title is the text 🔴 00:03; the emoji is a glossy 3-D ball, which is what reads as childish.
  • How the options are built: a tray icon can be swapped at any time, and an icon that isn’t a template image keeps its own colours. So A, B, C and E are one extra 44 px PNG each, swapped in when recording starts and back when it stops. D needs a few frames swapped on a timer. F draws the timer into the image every second.
  • Timer text stays the tray title (system font), as now, minus the emoji.
